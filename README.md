# Tylenol O-lens readouts

Site: the O-lens readouts of Qwen3.6-27B on the Tylenol prompt from the J-lens paper (Fig. 42), plus the
jacobian-lens walkthrough notebook with outputs.

- `index.html`: the readout dashboard. All 70 reads from 4 O-lens checkpoints (ceselder on Hugging Face).
- `notebook.html`, `walkthrough.ipynb`: the walkthrough from anthropics/jacobian-lens (Apache-2.0), run on Qwen3.5-4B.
- `slice.html`: the interactive slice page produced by the notebook.
